## Built With

- React.js
- Three.js
- Framer Motion
- TailwindCSS
- Vite

## Getting Started

Requires node `16.0.0` or higher and npm `9.0.0` or higher.

```
npm install
npm run dev
```

To build for production:

```
npm run build
```
